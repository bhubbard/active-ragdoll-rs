# Support for active-ragdoll-rs

If you encounter issues or have questions about using `active-ragdoll-rs`:

1. **Check Existing Issues**: Search the GitHub Issues tab to see if your question or issue has already been reported.
2. **Open an Issue**: If you have identified a bug or need support, open a new issue with complete reproduction steps and environment details.
3. **Discussions**: For feature requests, animation blending, or physics engine integration questions, use GitHub Discussions.
