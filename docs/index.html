How it works: The kinematic skeleton paces back and forth. The slave ragdoll's limbs are pulled towards the master using linear PD force signals and angular spring motors. When impacted by a projectile, muscle strength degrades, causing stumbling before restoring upright balance!

Engineered for Physical Realism

Key architectural components ported faithfully and optimized in Rust.

PD

Physical Animation Following

Target world Center of Mass (COM) for each limb is computed using local offsets. PD error signals generate VelocityChange impulses, combined with quaternion orientation joint drives.

PB

Push-Back Constraint

Prevents master from running away when the ragdoll gets caught or pinned against an obstacle. Applies a SmoothStep dampening force pushing the kinematic master back towards the ragdoll.

LM

Strength & Contact Filtering

Tracks limb collisions using 32-bit LayerMasks. Contact smoothly attenuates muscle strength to induce wobbles, while clearance recovers balance. Includes complete knockout (die()) and revival.

Master-Slave Feedback Loop

Data flow between Kinematic Master, Active PD Follower, and Physics Ragdoll:

1. Input & Kinematics

MasterController

SmoothDamp turning, walking/running gait cadence, procedural FK skeleton poses.

2. Control Drive

AnimationFollower

Calculates linear COM PD impulses and quaternion angular joint motor torques.

3. Physics Ragdoll

11-Bone Slave

Rapier3D or headless rigid bodies, spherical joints, collider contacts, gravity.

4. Pushback Feedback

Push-Back Spring

Restrains kinematic master distance; feeds back into next frame's motion vector.

use active_ragdoll_rs::prelude::*;
use glam::{Quat, Vec3};

fn main() -> Result<()> {
    // 1. Build standard 11-bone humanoid active ragdoll
    let mut setup = HumanoidActiveRagdollBuilder::standard_humanoid_11()
        .build()?;

    let limb_count = setup.limb_count(); // 11 limbs
    let input = LocomotionInput { horizontal: 0.0, vertical: 1.0, run: false };
    let dt = 0.02; // 50 Hz

    // 2. Step character locomotion and physics follower in one call
    let drive_outputs = setup.step_character(&input, true, &slave_states, dt)?;
    
    // 3. Each output contains linear force, target joint rotation, and spring/damping
    for (i, output) in drive_outputs.into_iter().enumerate() {
        println!("Limb {}: Force = {:?}, Target Rot = {:?}", i, output.linear_force, output.target_rotation);
    }
    Ok(())
}
use active_ragdoll_rs::prelude::*;
use rapier3d::prelude::*;

fn step_rapier_ragdoll(
    adapter: &mut RapierRagdollAdapter,
    master: &mut MasterController,
    bodies: &mut RigidBodySet,
    joints: &mut ImpulseJointSet,
    dt: f32,
) -> Result<()> {
    // Read slave hips position for push-back spring constraint
    let hips_pos = bodies.get(adapter.bindings[0].body).unwrap().translation();
    master.step(&LocomotionInput::default(), 0.0, hips_pos, true, dt);

    let poses = master.generate_master_poses();

    // Automatically extracts Rapier rigid body states, updates muscle strength,
    // and injects linear velocity impulses and angular torque impulses into Rapier
    adapter.step(&poses.world_transforms, &poses.local_rotations, bodies, Some(joints), dt)
}
use active_ragdoll_rs::prelude::*;

fn test_projectile_knockout(setup: &mut HumanoidSetUp) {
    // 1. Shoot ballistic projectile (port of ShootObject.cs)
    let mut projectile = Projectile::shoot(origin, forward, 21.0, 0.15, 5.0);

    // 2. Check impact on chest
    if let Some(impulse) = projectile.check_sphere_collision(chest_pos, 0.2, 20.0) {
        setup.on_collision_enter(LayerMask::ENVIRONMENT.bits().trailing_zeros() as u8);
    }

    // 3. Or trigger instant knockout (ragdoll collapses completely limp)
    setup.die();
    assert_eq!(setup.state(), RagdollState::Dead);
    assert_eq!(setup.current_strength(), 0.0);

    // Automatically recovers balance after dead_time (default 4.0s)
    setup.come_alive();
}
