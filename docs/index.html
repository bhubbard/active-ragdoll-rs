Core Capabilities

Built for Modern Game Physics

High-performance algorithmic character physics designed from scratch for Rust game engines and robotics simulations.

🎯

PD Linear & Joint Drives

Applies Proportional-Derivative forces to Centers of Mass to track master bone poses, with orthonormal joint space target rotation slerping and torque clamping.

⚡

Dynamic Strength Attenuation

32-bit layer-filtered contact detection. Characters lose strength and stumble during continuous collisions, recovering balance smoothly once freed.

🦴

11-Bone Biomechanical Rig

Standard humanoid rig with anatomically realistic mass distributions (~75 kg), joint attachment anchors, swing/twist limits, and per-limb tuning overrides.

🦀

Zero-Lockin + Rapier3D

Engine-agnostic core running on pure glam math, with optional rapier3d adapter synchronizing RigidBodies, joints, and impulses.

🎮

Kinematic Master & Push-Back

Smooth 3rd-person locomotion with SmoothDampAngle turning and push-back constraint ensuring the kinematic guide stays aligned when obstructed.

💀

Knockout & Timed Revival

Supports full loss of consciousness (die()) where joint torques cut to zero for limp ragdolling, followed by timed recovery back to standing.

Developer Guide

Get Started in Seconds

Add active ragdoll physics to your Rust project with Cargo.

Cargo.toml 
[dependencies]
active-ragdoll-rs = "0.1.0"
glam = "0.33"
rapier3d = { version = "0.36", optional = true }
main.rs — Standard Active Ragdoll Loop 
use active_ragdoll_rs::prelude::*;
use glam::{Quat, Vec3};

fn main() -> Result<()> {
    // 1. Build a standard 11-bone humanoid active ragdoll
    let mut ragdoll = HumanoidActiveRagdollBuilder::standard_humanoid_11()
        .build()?;

    let dt = 0.02; // 50 Hz physics step
    let limb_count = ragdoll.limb_count();

    // 2. Supply animated master transforms and current slave physics states
    let master_world = vec![Transform3d::IDENTITY; limb_count];
    let master_local = vec![Quat::IDENTITY; limb_count];
    let slave_states = vec![
        SlaveLimbPhysicsState {
            world_center_of_mass: Vec3::ZERO,
            world_rotation: Quat::IDENTITY,
            local_rotation: Quat::IDENTITY,
            angular_velocity: Vec3::ZERO,
        };
        limb_count
    ];

    // 3. Step active ragdoll physics
    let drive_outputs = ragdoll.update(&master_world, &master_local, &slave_states, dt)?;

    for (i, drive) in drive_outputs.iter().enumerate() {
        // Apply linear force impulse to slave rigid body
        println!("Limb [{}] force: {:?}", i, drive.linear_force);
    }

    Ok(())
}
