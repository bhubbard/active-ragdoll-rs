# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in `active-ragdoll-rs`, please report it by opening a private security advisory on GitHub or by contacting Brandon Hubbard directly.

Please include:
1. Description of the vulnerability.
2. Steps or minimal code example to reproduce.
3. Potential impact.

We strive to address critical security concerns promptly.
